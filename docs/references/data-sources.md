# Data sources

What each outside source gives Layover, its access terms and limits, and when that was last checked. Re-check a source's terms before building with it, and update this page in the same pull request.

Checked on 19 Nov 2026 unless a row says otherwise.

## Earnings (Travelpayouts)

Read in a browser on 19 Nov 2026 (the help centre blocks automated fetches). How Layover uses them: the register line "Aviasales links are built by the backend…" in [decisions](../decisions/README.md#register).

| Source | What it gives | Access | Limits and notes |
|---|---|---|---|
| [Partner links API](https://support.travelpayouts.com/hc/en-us/articles/25289759198226-API-for-Travelpayouts-partner-links) | Turns a direct brand link (for example an Aviasales search) into a partner link: `POST https://api.travelpayouts.com/links/v1/create` with `trs` (project ID), `marker` (partner ID), `shorten`, and links each with an optional `sub_id` | API token in the `X-Access-Token` header; the brand's programme must be joined | 100 requests a minute per marker; at most 10 links a request; use full-length links. **Needs a project ID (`trs`)**. Travelpayouts asks for a link to a traffic source when a project is created, so the project waits for a site (register: "Create the Travelpayouts project after the repository or site exists") |
| [Booking statistics API](https://support.travelpayouts.com/hc/en-us/articles/360019864079-API-of-affiliate-programs-booking-statistics) | Bookings, paid clicks, earnings and states (paid, processing, cancelled) per action, each with its `sub_id`; grouped counts such as `redirects_count` (clicks) and `paid_profit_<currency>_sum`. `GET /statistics/v1/get_fields_list`, `POST /statistics/v1/execute_query` | API token in the `X-Access-Token` header | A date filter is required; up to 10,000 rows a request; general API rate limits apply. The examples group by device; grouping clicks by `sub_id` is **not shown** on the page, so check it with `get_fields_list` before building the dashboard |
| [ID and SubID](https://support.travelpayouts.com/hc/en-us/articles/203955653-ID-and-SubID-Affiliate-marker-and-additional-marker) | The partner ID (marker) is added to every tool and kept in a cookie for 30 days unless a programme says otherwise; a SubID labels a placement or tool | — | SubIDs use Latin letters, digits and `_`, up to 4,096 characters; reports can filter and group by SubID (Reports → Performance). Some SubIDs are reserved service markers (`cal`, `tpsub`, `map` and others), so Layover's names must avoid them |
| [Payout methods](https://support.travelpayouts.com/hc/en-us/articles/206635007-Payout-methods) and [timing](https://support.travelpayouts.com/hc/en-us/articles/360012173520-How-often-are-payouts-made) | **Reference only. The owner sets payouts up; agents never enter payment details.** Methods depend on the country of residence: bank transfer in USD or EUR (minimum 400), PayPal (minimum USD 50), WebMoney (minimum USD 10) | Owner's Travelpayouts account | Paid automatically once a month, between the 11th and 20th, if the minimum was reached by the end of the previous month and payout details were in by the 9th |

## Possible extras through Travelpayouts (no brand approval)

From [Brands that provide access to APIs and data feeds](https://support.travelpayouts.com/hc/en-us/articles/20384016664594-Brands-that-provide-access-to-APIs-and-data-feeds-for-Travelpayouts-partners). Each brand has its own terms in its documentation; read them before use.

Priority: intui.travel and Airalo first, because transfers and mobile data are real trip costs a UK traveller forgets; then GOV.UK bank holidays and Nager.Date (in [Candidates](#candidates-free-not-yet-chosen)). Joining these programmes is a later choice; for now only Aviasales is joined (register).

| Brand | What it gives | Possible use for a UK holidaymaker | Priority |
|---|---|---|---|
| Omio | Feed of popular destinations by country (trains, buses) | Rail options, e.g. Eurostar trips | — |
| intui.travel | Transfer search with prices, airport route lists, booking links | Airport-to-hotel transfer cost | 1 |
| Airalo | eSIM prices by country and region, validity, operator | Mobile data cost abroad | 2 |
| Tiqets | Cities and offers (for widgets) | Attraction tickets | — |
| Viator | Feed of discounted tours (deals only, not a full catalogue) | Tour deals | — |
| WeGoTrip | Self-guided quest tours, cities, reviews | Niche activities | — |

**No hotel data:** no hotel brand (Booking.com or others) appears on that list, so Travelpayouts gives no hotel prices. How Layover handles hotels is an open design question.
