# Build step 1: foundation and data contract (implementation plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running FastAPI backend and Next.js website, with the data contract for the trip and all 20 widget kinds fixed, every widget built in every state from the boards' sample data, and Aspire starting it all locally. No model calls and no outside data.

**Architecture:** Pydantic models in `backend/src/app/contract/` are the one true copy of each widget's shape. They are exported to `schemas/*.schema.json` and, through OpenAPI, to TypeScript (`frontend/src/lib/api/schema.d.ts`). Shared sample files in `schemas/samples/` feed backend tests, the sample endpoints and the frontend. The frontend is React with Tailwind v4 over Layover's tokens, with the boards as the visual reference.

**Tech Stack:** house-template-fastapi v0.11.1 (FastAPI 0.162, Pydantic, SQLAlchemy 2.1, PostgreSQL with pgvector, pytest), house-template-nextjs v0.3.0 (Next.js 16, React 19, Tailwind v4, Vitest, Playwright), `holidays`, Lucide, Aspire (TypeScript app host), OpenTelemetry.

**Spec:** [docs/superpowers/specs/2026-11-21-build-step-1-design.md](../specs/2026-11-21-build-step-1-design.md). Executors read both.

## Global Constraints

- No model calls, no LangChain or LangGraph code, no outside API calls in any test that runs in `make check`.
- FastAPI layer answers: `database: true`, `llm: none`, `storage: false`. Next.js layer: backend `fastapi`.
- Packages: the two template layers' sets, `holidays`, Lucide, the Aspire CLI and app-host npm packages, and OpenTelemetry PostgreSQL instrumentation are approved. Any other package: stop and ask the owner.
- Every package gets a `docs/references/third-party.md` entry with its version, licence and official documentation link.
- Money is integer minor units with an ISO 4217 code, or `Decimal`. Never a float. Rounding: full precision through a calculation, then once to the minor unit, half up. Estimates are shown to the nearest £10, half up.
- Every outside value carries a source label: Live, Cached with its age, Fallback or Unavailable (decision 0011 rule 2). Missing data is `None` with a `not_known` state, never `0`, `""`, `"N/A"`, `"TBC"` or a dash (rule 4). No fixed copy calls a destination "safe" (rule 6).
- Interface wording follows the [naming conventions](../../design/information-architecture.md#naming-conventions): "Not known", "Cached, 3 days old", "Sandbox: no real booking or payment", "From a web search, not checked by Layover", "FCDO travel advice" with "updated" and a date.
- Every page that shows the sample trip shows the label "Sample trip".
- Styling is Tailwind v4 over Layover's tokens: no literal colours, radii or fonts in components.
- Accessibility: WCAG 2.2 AA; one `h1` per page; colour never carries meaning alone.
- Expected figures in tests are hand-worked, with `Working:` and `Source:` in the test's docstring (`test-first` skill).
- Branches `type/short-description`; Conventional Commit titles with a lowercase subject; no agent attribution in commits or PRs.
- `make check` passes before every push.

## Review Focus

1. **A trip or share URL other than `sample-lisbon`** (`/trip/abc`, `/s/x`): the "Link not found or expired" page, not an error page or a crash. Tests: Task 17.
2. **A widget whose value is missing** (`None` with state `not_known`): shows "Not known" and says what is missing, never `0`, `£0`, a dash or "N/A". Tests: Task 14 (shared), each widget task.
3. **Phone width (390 px) with the longest sample text** (long place names, long hotel names, a fare range with two prices): no sideways scroll, no clipped text. Tests: Task 17's Playwright phone-width run on every page and on the gallery.
4. **Dark mode source labels:** Cached, Fallback and Unavailable stay readable and are told apart by their words, not only colour. Tests: Task 14.
5. **The gallery in production:** `/dev/widgets` answers 404 when `ENABLE_WIDGET_GALLERY` is unset. Tests: Task 18.
